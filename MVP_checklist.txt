
# MVP & Reglas de Negocio - SkyWay

## Registro y autenticación de usuarios
- [ ] Registro único (RUT, email, documento) y asignación de rol
- [ ] Inicio/cierre de sesión, bloqueo tras intentos fallidos
- [ ] Recuperación de contraseña y validación de datos

## Gestión de vuelos
- [ ] Crear/editar vuelos (origen ≠ destino, fechas válidas, estado)
- [ ] Asignar avión operativo y disponible (sin solapamiento)
- [ ] Asignar tripulación mínima y certificada
- [ ] Cancelar/reprogramar vuelos con notificación y motivo

## Asignación y gestión de tripulación
- [ ] Registrar tripulantes con licencia y cargo
- [ ] Asignar a vuelos/turnos sin solapamiento ni exceso de horas
- [ ] Confirmar/rechazar turnos (con motivo y fecha)

## Gestión de turnos
- [ ] Crear turnos (tipo, horario, límites legales)
- [ ] Visualizar y confirmar/rechazar turnos (requiere aprobación admin para cambios)

## Reserva y gestión de asientos
- [ ] Visualizar disponibilidad y clase
- [ ] Reservar/cancelar asientos (no doble reserva, límite de tiempo)
- [ ] Aplicar reglas de tarifa (cambios/cancelaciones según tipo)

## Panel de administración
- [ ] CRUD de usuarios, vuelos, tripulación, aviones, reservas
- [ ] Reportes: ocupación, puntualidad, incidencias, ingresos
- [ ] Monitoreo en tiempo real

## Perfiles de usuario
- [ ] Visualizar/editar datos personales
- [ ] Historial de vuelos, turnos y reservas

## Interfaz y experiencia de usuario
- [ ] Navegación clara, validaciones y mensajes de error
- [ ] Estilos visuales coherentes y accesibles
- [ ] Multilenguaje y personalización por rol

## Documentación
- [ ] README con descripción, funcionalidades y pasos de uso
- [ ] Comentarios y ejemplos en el código

## Pruebas y calidad
- [ ] Pruebas manuales de todos los flujos
- [ ] Tests automáticos básicos (opcional)
- [ ] Eliminar código muerto y funciones incompletas

## Despliegue
- [ ] Verificar ejecución en producción
- [ ] Instrucciones claras de instalación y uso

## Reglas de negocio para tarifas
- [ ] Tarifa Básica: no permite cambios de asiento, sí cancelación
- [ ] Tarifa Flexible: permite cambios hasta 48h antes, sí cancelación
- [ ] Tarifa Premium: permite cambios hasta 24h antes, sí cancelación
- [ ] Validar reglas en cada acción de reserva, cambio y cancelación
