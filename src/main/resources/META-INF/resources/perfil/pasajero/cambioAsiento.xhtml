Instrucciones de Asientos

¿Cómo funciona la selección de asientos?

Los asientos se presentan en diferentes estados, y puedes ver claramente cuál está disponible, cuál ya ha sido ocupado y cuáles fueron seleccionados originalmente para ti.

Asiento Disponible - Puedes seleccionar este asiento.
Asiento Ocupado - Este asiento ya ha sido reservado por otro pasajero.
Asiento Originalmente Seleccionado - Este asiento era tu selección inicial.
